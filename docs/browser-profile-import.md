# Browser profile import

Browser settings → Import profiles discovers installed applications using Launch Services bundle IDs. It inspects profile metadata without opening Keychain. The catalogue includes Chrome, Chromium, Edge, Brave, Arc, Dia, Vivaldi, Opera, Firefox and their listed variants, plus Safari, Orion and DuckDuckGo. Browsers without an implemented storage reader are shown with an unsupported message. Importable profiles have a selector and an Import button; Refresh repeats discovery.

If macOS denies access to a profile folder, clicking **Import** opens the native folder picker at that browser’s data folder. Selecting it grants access and continues the requested import when there is one profile; with multiple profiles, the user chooses which to import. There is no separate permission button or picker when folder access already works. Talaria remembers the selection with a read-only security-scoped bookmark for subsequent launches. Folder access errors remain visible, and no system privacy settings or source file permissions are changed. See [Apple’s file access guidance](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox).

The source browser can stay open. Chromium cookies are read through an online SQLite backup (including WAL, with bounded retries for contention), decrypted using its macOS Safe Storage key and imported through CEF's cookie manager. Host binding, host-only/domain scope, expiry, Secure, HTTP-only and SameSite attributes are preserved. Firefox supports both second- and millisecond-based cookie schemas and compressed UTF-8/native UTF-16 local storage. Partitions, containers, extension origins and expired cookies are skipped and counted.

Chromium local storage is read from a private LevelDB snapshot without acquiring or changing the source lock. The importer inventories database filenames, file identities, sizes and nanosecond modification/change times before and after copying CURRENT, manifests, tables and WAL. If a write, replacement or compaction changes the inventory, it discards the copy and retries up to five times. The reader then recovers only the private copy, observing manifests, tombstones, WAL and checksums. A continuously changing or unreadable source reports a retryable error before any data is imported. Data not yet flushed by the browser is unavailable; cookies and local storage reflect independent snapshots.

Local storage entries are staged in a mode-0600 file inside Talaria's profile. Before CEF initializes, a synchronous atomic LevelDB batch merges them into `Default/Local Storage/leveldb`, replacing matching keys and retaining other entries. Metadata is recalculated. Session cookies are replayed once after the required restart, without making all future session cookies persistent. Clear cookies also cancels pending session-cookie restoration.

Unsupported encryption or database formats produce an error; no source databases are rewritten. This imports cookies and local storage, not passwords, bookmarks, history, IndexedDB or extensions. Browser versions with alternate storage formats may require another reader.

## Validation

- `make test-browser-import`: disposable Chromium/Firefox fixtures, live source locks, SQLite WAL transactions, concurrent writes/compaction, encryption, tombstones, expiry, encoding, private staging and locked destinations.
- `make test-browser-import-ui`: full settings workspace, profile selection, busy/completion states, 200px/700px layouts and rendered themed button states.
- `make test-browser-import-cef`: signed desktop probe with a loopback fixture, three launches verifying local storage, HTTP-only protection, persisted cookies and one-time session restoration.

Format references: [Chromium cookie schema](https://chromium.googlesource.com/chromium/src/+/main/net/extras/sqlite/sqlite_persistent_cookie_store.cc), [Chromium local storage schema](https://chromium.googlesource.com/chromium/src/+/main/components/services/storage/dom_storage/leveldb/local_storage_leveldb.h), [Firefox cookie migrations](https://searchfox.org/firefox-main/source/netwerk/cookie/CookiePersistentStorage.cpp), [Firefox local storage encoding](https://searchfox.org/firefox-main/source/dom/localstorage/LSValue.cpp). Dependency versions and licenses are recorded in `Vendor/browser-import/PROVENANCE.md` and included in the app bundle.
